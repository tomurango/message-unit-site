プライバシーポリシー

Message Unit ／ 制定日: 2026年9月29日

Message Unit（以下「本アプリ」）は、開発者本人が自分の Google アカウントで使う個人用の macOS アプリです。本アプリが Google ユーザーデータをどう扱うかを以下に定めます。

1. 取得するデータ

利用者が Google アカウントでログインして許可した場合に限り、Gmail API を通じて次のデータを取得します。

  • 利用者のメールアドレス
  • 受信トレイ・送信済みメールの送信者、宛先、件名、日時、抜粋、本文

要求する権限は gmail.readonly（メールの読み取り）と gmail.send（メールの送信）です。

2. 利用目的

  • やり取りを相手ごとにまとめて表示し、返信を待っている相手を知らせるため
  • 利用者が画面で内容を確認したうえで指示したメールを送信するため

上記以外の目的には使いません。広告、利用者の行動分析、機械学習モデルの学習には使いません。

3. 保存場所

取得したデータとログイン情報（OAuth トークン）は、利用者の Mac の中だけに保存します。開発者のサーバーやクラウドには送信・保存しません。ログイン情報は、利用者本人しか読み書きできない権限のファイルに保存します。

4. 第三者への提供

Google ユーザーデータを第三者に提供、販売、共有することはありません。

5. データの削除

  • アプリの設定画面で「ログアウト」すると、ログイン情報を削除します。
  • 取り込んだメッセージは、利用者の Mac のデータフォルダを削除すれば消えます。
  • Google アカウントの サードパーティのアクセス設定 から、本アプリの権限をいつでも取り消せます。

6. Google API サービスのユーザーデータに関するポリシーの遵守

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、限定使用の要件を含め、Google API サービスのユーザーデータに関するポリシーに従います。

7. 変更

本ポリシーを変更する場合は、このページを更新します。
